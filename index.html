📚 About Password Hashing

Password hashing is used to convert a password into a fixed-length value called a hash. The original password is not directly stored.

Even a small change in the password usually produces a completely different hash.

🔎 About the Hash Algorithms

MD5

MD5 produces a 128-bit hash, which is 32 hexadecimal characters long. It was commonly used in the past, but it is now considered weak and should not be used for secure password storage.

SHA-1

SHA-1 produces a 160-bit hash, which is 40 hexadecimal characters long. It was used in many older security systems, but it is now considered outdated for security purposes.

SHA-256

SHA-256 produces a 256-bit hash, which is 64 hexadecimal characters long. It is commonly used in cybersecurity and data integrity applications.

SHA-512

SHA-512 produces a 512-bit hash, which is 128 hexadecimal characters long. It belongs to the SHA-2 family and is used in many cryptographic applications.

🛡️ Security Information

🔒 Hashing

Hashing is a one-way process used to create a fixed-length value from data.

⚠️ MD5 & SHA-1

MD5 and SHA-1 are old algorithms and are not recommended for modern security applications.

🔐 Password Security

Real password systems usually use algorithms such as Argon2id, bcrypt or scrypt.
